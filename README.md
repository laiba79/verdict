# 🤖 HR Decision Support System (AI & Machine Learning)

An intelligent **HR Decision Support System** that leverages **Machine Learning**, **Large Language Models (LLMs)**, and **Resume Analysis** to help HR teams make smarter, faster, and more data-driven recruitment decisions.

The system combines a modern React frontend with a FastAPI backend to provide candidate evaluation, employee management, predictive analytics, and AI-powered recruitment assistance.

---

## ✨ Features

### 👥 Employee Management

* Add, edit and delete employee records
* Employee history tracking
* Role-based access control
* Secure authentication & authorization

### 📄 AI Recruitment System

* Upload candidate resumes
* Automatic resume parsing
* Job Description (JD) management

# 🚀 Installation

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/HR-Decision-System.git
cd HR-Decision-System
```

---

## 2. Backend Setup

```bash
cd hr-backend

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Backend runs on:

```
http://localhost:8000
```

---

## 3. Frontend Setup

```bash
cd hr-frontend

npm install

npm run dev
```

Frontend runs on:

```
http://localhost:5173
```
